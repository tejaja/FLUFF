# たんぽぽの冠毛（上から見た放射状の細い毛）の半透明テクスチャ。白、アルファで形
import sys, math, random
import numpy as np
from PIL import Image

N = 256
out = sys.argv[1]
rng = random.Random(7)
ss = 4  # スーパーサンプリング
M = N * ss
acc = np.zeros((M, M), np.float32)
c = M / 2

def stroke(x0, y0, x1, y1, w0, w1, a0, a1, steps):
    for i in range(steps + 1):
        t = i / steps
        x = x0 + (x1 - x0) * t; y = y0 + (y1 - y0) * t
        w = w0 + (w1 - w0) * t; a = a0 + (a1 - a0) * t
        r = max(1, int(math.ceil(w)))
        xi, yi = int(x), int(y)
        ys = slice(max(0, yi - r), min(M, yi + r + 1)); xs = slice(max(0, xi - r), min(M, xi + r + 1))
        yy, xx = np.mgrid[ys, xs]
        d = np.sqrt((xx - x) ** 2 + (yy - y) ** 2)
        v = np.clip(1.0 - d / max(w, 0.5), 0, 1) * a
        acc[ys, xs] = np.maximum(acc[ys, xs], v)

# 主な毛：中心から放射状。先に向かって細く・薄く、少しだけ曲がる。毛先に細い枝毛
n = 44
for k in range(n):
    ang = 2 * math.pi * k / n + rng.uniform(-0.06, 0.06)
    L = c * rng.uniform(0.80, 0.97)
    bend = rng.uniform(-0.12, 0.12)
    pts = []
    seg = 8
    for s in range(seg + 1):
        t = s / seg
        a = ang + bend * t * t
        pts.append((c + math.cos(a) * L * t, c + math.sin(a) * L * t))
    for s in range(seg):
        t0 = s / seg; t1 = (s + 1) / seg
        stroke(*pts[s], *pts[s + 1], 3.2 * (1 - 0.7 * t0), 3.2 * (1 - 0.7 * t1), 0.95 - 0.55 * t0, 0.95 - 0.55 * t1, 40)
    # 枝毛（外側半分に数本、斜めに）
    for b in range(3):
        t = rng.uniform(0.45, 0.85)
        bx, by = c + math.cos(ang) * L * t, c + math.sin(ang) * L * t
        side = rng.choice((-1, 1)) * rng.uniform(0.25, 0.45)
        bl = L * rng.uniform(0.12, 0.22)
        stroke(bx, by, bx + math.cos(ang + side) * bl, by + math.sin(ang + side) * bl, 1.6, 0.8, 0.5, 0.15, 20)

# 中心の小さな点（冠毛の付け根＝星の真ん中）
yy, xx = np.mgrid[0:M, 0:M]
d = np.sqrt((xx - c) ** 2 + (yy - c) ** 2) / c
acc = np.maximum(acc, np.clip(1 - d / 0.07, 0, 1) ** 0.7)
# うっすら全体のもや（ふわっと感）
acc = np.maximum(acc, np.clip(1 - d, 0, 1) ** 2.2 * 0.18)

img = acc.reshape(N, ss, N, ss).mean(axis=(1, 3))
img = np.clip(img, 0, 1)
rgba = np.zeros((N, N, 4), np.uint8)
rgba[..., 0:3] = 255
rgba[..., 3] = (img * 255).astype(np.uint8)
Image.fromarray(rgba, "RGBA").save(out)
print("ok", out)
